# 《異鄉田園》設計與開發範圍

## 已確認的方向

原創異世界，融合唐宋與西方中世紀生活文化；像素風、俯視角、星露谷向生活養成，目標 Android／iOS。參考經典像素遊戲的可讀性與生活節奏，採用原創世界、美術及角色。

玩家因「星潮」來到東西商路交會的雲橋鎮，接手荒廢驛站莊園。透過農耕、加工、居民交流與輕度冒險，修復莊園及商路，逐漸理解穿越的原因。

融合由城鎮歷史與日常生活呈現：青瓦木樓、石橋、木構商鋪、茶園、磨坊、瓷窯與鍛冶工坊。符印術與晶石術是同一種魔力的不同應用。

## 核心循環

整理田地 → 播種與照料 → 收穫與加工 → 出售／送禮 → 升級工具與設施 → 解鎖區域與故事。

日常以農耕為核心，人際與探索提供變化。沒有現實時間體力等待、離線作物死亡或連續登入懲罰。建議商業模式為免費試玩＋一次買斷，價格與付費功能尚未實作。

## 下一階段：垂直切片

進入內容擴充前，先交付 0.2 Android 手機試玩版：ARM64 APK、螢幕安全區域、多指及長按作業、背景恢復、返回鍵及安裝驗證。手機實機手感與效能由實際試玩確認；詳見 ANDROID_TESTING.md。

優先依試玩調整工具手感、移動、可讀性及手機介面，再逐項擴充：

1. 正式像素素材、角色動作、環境音與操作音效。
2. 莊園、住宅室內、小鎮、林地與一處小型遺跡。
3. 一個完整春季、約八種作物、兩種養殖動物及少量加工設備。
4. 六位居民的作息與個人事件，一場節慶。
5. 修復莊園、恢復第一條商路的主線。
6. 採集、簡單戰鬥與遺跡事件。
7. Android 實機驗證、iOS 匯出及試玩發行準備。

四季、戀愛婚姻、更多幻想動物與探索區域待試玩後擴充。多人連線、大規模城鎮建造與複雜自動化不列入首發範圍。原型沒有植入帳號、廣告、支付或遠端服務。

0.3 已完成第 1 項的第一輪素材與聲音實作：原創圖集、四方向角色／工具動作、晴雨環境聲、背景音樂與音量設定。視覺與操作仍會持續修整，尚未視為最終美術定稿；0.4 已接續完成住宅室內與小鎮，詳見 MAPS.md。

0.4 提供三張可往返地圖、室內床鋪與手札、小鎮商人與鐵匠、公告牌與過橋尋路。青禾移至小鎮，沿用初耕委託與好感度。0.5 已加入霧杉林採集、材料背包、草茶與一次性圍欄修復。0.6 已加入單座烘乾架、三種加工成品與隔日領取出貨。0.7 已加入三種居民委託、青禾窗邊茶會與手札回顧；後續可擴充更多修復項目與其他居民事件；0.8 已加入雞舍、最多三隻母雞、小麥餵食、隔日產蛋與雞蛋出貨。0.9 已加入修復驛路主線、第五張遺跡地圖、雙語碑文與星紋殘片發現；尚未實作戰鬥、其他養殖動物或新季節。

0.10 已加入魚竿製作、三地垂釣、咬鉤收線與魚獲出貨，提供農耕之外的每日活動。每竿 2 體力、每日最多三尾，沒有現實時間冷卻。尚未加入魚餌、魚類加工或工具升級。

0.11 已加入三種料理、農舍爐灶選單與可隨身食用的料理背包，串連種植、雞蛋及魚獲的用途。出貨會保留餐點，滿體力不浪費食物；尚未加入贈禮、料理品質或食譜解鎖。

0.12 已加入田間作業狀態：工具動作時站定，完成後執行最後點擊的目的地；保留鍵盤與手機雙指長按，操作成功立即保存，中斷不重播。這是操作改善，沒有加入新的作物或地圖。

0.13 主角改用八方向獨立圖像，補齊四個斜向的站立、行走與工具姿勢；保持等速移動與原有工具鎖定。居民固定站位及現有地圖玩法繼續沿用。

0.14 已加入角色外觀預覽，提供八方向與站立、步行、作業姿勢的近距離查看；移動面向交界加入角度緩衝，保持原輸入方向、速度及工具目標。

## 驗收方式

新玩家可從澆水開始，睡眠後採收、出售、購買種子並完成下一輪種植；關閉重開後進度一致。介面暫停時時間不流逝，體力不足不會扣除種子或銀幣，獎勵與出貨不可重複領取。

目前以自動化場景測試與 Linux 軟體渲染驗證。尚不能由此推論手機效能、實體觸控體驗或商店上架相容性。
