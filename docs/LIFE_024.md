# 0.24 春夏相知：計劃 1～7 的可玩版本

本輪依序實作操作、新手、農場配置、動畫、關係、經濟及季節探索。未執行第8項商店上架準備；APK延用原有測試簽章。主要入口：右上「手札」→ 莊園生活手札。手機手感在「選單」→「手機手感」。

## 1. 手機操作與穩定

- 觸控取消、控制項隱藏、離開場景、切背景或失去焦點時清除按住狀態；取消事件不再觸發放開型按鈕。
- 背景與焦點狀態各自阻擋遊戲更新，即使視窗被關閉也不繼續走路。畫面尺寸／安全區改變時清除方向盤、尋路和排隊操作。
- 單次長幀的移動距離最多按0.1秒計算，避免瞬間跨過障礙；正常遊戲時間與作業按delta推進。
- 手感可調：148／160方向盤，25%／35%中央防誤觸；「點目標走近」可關閉，改為方向盤手動走近後點選作業。設定獨立保存，改動前先停止移動。
- 固定地面由獨立節點保留繪製，角色每幀重畫時不重新建立整片地磚命令。30／60 FPS 選項保留。
- 自動化覆蓋實際場景、觸控版面與生命週期；104次反覆切換地圖檢查節點與靜態記憶體。這不是實體手機的FPS、發熱、電量或長時遊玩驗證，仍需用安裝包實測。

## 2. 可跟隨的新手任務

開場可直接進入逐步任務。五項任務依成功操作永久記錄：澆水 → 休息 → 採收 → 出貨 → 重新播種。畫面上方顯示目前第一個未完成目標；手札可重看並準備工具。失敗操作不算完成，瀏覽任務不加資源、不中斷既有進度。

舊版沒有逐步旗標時從未完成開始，避免推測玩家曾做過哪些操作；玩家可以略過手札繼續原有玩法。每一項可獨立完成，不會因先做後面的步驟而卡住。

## 4. 角色與生物動態

男女主角保留八方向移動與四種工具作業；待機增加前方眨眼、呼吸與定時伸展。眼瞼依原圖前方站姿座標繪製，原PNG不修改。背面／側面不加正面眼瞼。居民沿既有日程移動時增加腳步擺動，停留時呼吸；仍使用已通過的正面居民素材，未新增完整八方向NPC圖集。

月絨兔跳動、蜜翼蜂懸浮、星鱗鯉漣漪、餵食碎粒與晚間休息提示補上生命感。這些表現不推進生產、不扣體力或改動存檔座標。

## 5. 九位居民的關係

九位居民都可送禮：青禾、洛安、雷恩、艾德里克、莉莉雅、博林、雲霽、素月、青麟。每人每日收一份；喜愛物好感+2，其餘可選禮物+1，需實際走近本人。名冊顯示當前位置、喜好與持有數，遠處可查看但不能送出。

好感3熟識、10信賴、25知心。既有相識故事保留，每人新增信賴／知心相處回憶，按順序完整讀完才領80／150銀，各一次。中途關閉不領獎，兩段已完成回憶都能重讀，不再發獎。每日上限與完成狀態隨存檔保存。

## 6. 經濟與體力

工藝採原材料＋明示工費，仍休息一日完成；舊版已接單不追補費用。飼料即做即取不收工費。月絨雲錦8、蜂蜜春茗8、苔絨暖毯10、青玉護符12、星露靈燈10、符玉灌溉器20銀。材料或銀幣不足不會部分扣除。

新增水壺調校：180銀、木材8、石料6，一次建造後每次澆水體力2→1；沿用水壺外觀。既有棲地與動物費用保留，避免改價破壞上一版已建立的進度。

手札可開啟「保留出貨」：每種作物、加工品、養殖品、工藝品、魚與雞蛋各留2份，只出售多餘部分。預設關閉以保留原來的一次出貨行為；種子、素材、料理一直保留。金額溢出或沒有可售品時完整回復數量。

收益試算見 [balance-0.24.json](balance-0.24.json)：採用實際售價、成熟日、工費、成年產出間隔及購買飼料成本。檢查春夏作物、養殖與工藝都維持正現金毛利；木石採集與玩家時間另計，不宣稱所有玩法收益相同。

春季每4日細雨；夏季每5日循環中第2／3日連續夏雨。日曆和睡前預報採同一規則，雨水替已開墾田地補水。

春宴只在春14至28日開放。夏14至28日在雲橋鎮舉辦星燈夜：提供三種不同作物各一份，完整讀完兩幕相聚，領一次150銀。夏季供品和獎勵與春宴分開保存，每個春夏年一次，重讀不重複領取。

## 相容性與限制

沿用版本1存檔，新增可選journey欄位；0.23與更早的有效存檔可載入。對應實際累計日數顯示春夏；原作物、貨幣、關係、春宴及章節紀錄保留。新欄位有型別、數量、日期與關係門檻驗證，備份碼一併包含它們。建議更新前建立備份並匯出完整備份碼。

此版完成上述可玩功能與自動化驗證，尚不等於實機驗收全部完成。也沒有自由搬房屋、秋冬、戰鬥、完整新NPC方向圖、雲端存檔或商店上架。
