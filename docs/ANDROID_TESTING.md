# Android 手機試玩版 0.22

## 0.22 本輪優先檢查

- 左手按住搖桿中央，右手點世界物件：應不啟動尋路。放開第一指後應停止；另一指放開不能取消正確手指。
- 工具按鈕拖出後放開，不應繼續連續作業。「停止移動」能清掉當前尋路與搖桿殘留。
- 切背景、鎖屏、返回遊戲仍應停在選單；請特別回報仍出現失控的手機型號與步驟。
- 主角停下時應有微幅呼吸與重心變化，世界座標與體力不因此改變。
- 檢查屋內、農場四個角度行走、田格及主要入口；小鎮石地、店鋪與人物配色是否更一致。
- 右上「行旅」到四聚落；晴天11至18時找居民，雨天或其他時段回牧場。
- 依配方製作飼料、工藝品與料理；工單休息一日後回原工坊領取，重開不可重複領取。
- 相識故事中途關閉無獎，重讀不重複發錢；每日委託只能交付一次。

詳細配方、建造費與驗證範圍見 [0.22 說明](REFINEMENT_022.md)。

## 安裝

安裝檔：build/android/arise-prototype-0.22.0.apk。0.14 與先前版本仍保留。

新增試玩項目與養殖規則見 [雲橋靈牧 0.21](RANCH_021.md)。

目前針對 Android 7.0／API 24 或以上、ARM64、支援 OpenGL ES 3.0 的裝置建置。這是測試簽章的 APK，尚未上架 Google Play，也不適用 iPhone。

1. 將 APK 下載或傳到 Android 手機。
2. 點擊 APK；若系統詢問，僅允許這次使用的瀏覽器或檔案管理員「安裝未知應用程式」。
3. 完成安裝後，從桌面開啟「異鄉田園」。
4. 試玩完畢可關閉該來源的安裝權限。

不需要帳號與網路；安裝包沒有宣告相機、位置、網路或儲存空間等權限。存檔使用應用程式自己的資料目錄。

安裝更新時請保留舊版並直接覆蓋安裝，以保留資料。若顯示簽章衝突，代表先前版本使用另一把測試金鑰；請先保存原資料，不要為了安裝而直接移除舊版。解除安裝會刪除本機進度，本版沒有雲端備份。

## 0.21 優先實機檢查

1. 在搖桿按住移動、拖出邊界後放開；角色應停止。第二指點工具後放開，不應影響第一指。
2. 點空白地面不應在手機啟動尋路；點作物、建築與居民仍走近互動。接觸搖桿立即取消舊尋路。
3. 移動時切背景、鎖屏後恢復；應停在選單，不能自行前進。
4. 選單 → 旅人造型 → 男女旅人；切換並重開確認保存，八方向與作業需逐向觀察。
5. 牧場 → 四組棲地 → 牧場手冊 → 建造；領養後取名、餵食、照料、休息再查看成長與產物。
6. 七種新增生物使用照料飼料；既有母雞使用收成小麥。幼體成熟後才開始累積產物。

8. 覆蓋 0.14 後，檢查舊母雞、巢箱、雞蛋與存檔保留。請勿先解除安裝。

## 本版操作改善

0.14 加入面向交界緩衝與「角色外觀」預覽，可查看八個方向及站立、步行、作業姿勢；預覽不改變玩家進度。方向緩衝只影響顯示，不改移動角度或速度，作業時立即朝向目標。詳見 [旅人身影](CHARACTER_PREVIEW.md)。

0.13 主角加入八方向站立、行走與工具圖像；斜向不加速，放開搖桿保留最後面向。使用腳底支點對齊 64 個姿勢，不改碰撞範圍或存檔欄位。詳見 [八方向角色](EIGHT_DIRECTIONS.md)。

0.12 工具操作成功後站定約 0.30 秒，期間固定面向，結束後才恢復移動。期間點擊保留最後一個目標；可先換下一件工具。成功操作立即存檔，開選單／背景／切區會清除動作與待出發點擊，保留已完成的田地效果。詳見 [工具操作](TOOL_ACTIONS.md)。

0.11 新增農舍爐灶選單、三張食譜、料理背包與隨身食用。草茶保留；料理留作食用，不被出貨箱出售。版本 1 舊存檔缺少 meals 時預設空料理，製作與食用成功立即保存。詳見 [料理玩法](COOKING.md)。

0.10 新增魚竿、三處釣點、三種魚獲及出貨；沿用版本 1 存檔，舊檔自動補齊釣魚欄位。投竿即保存體力消耗，背景／鎖屏取消當前一竿，回前景停在選單。詳見 [釣魚玩法](FISHING.md)。

## 重複建置（Linux x86_64）

需求：Godot 4.6.3、Python 3.12+、網路、約 6–8 GB 可用空間。初次安裝會下載官方 Godot 模板、Android 工具、完整 JDK 17、NDK 及 Gradle；SDK manager 會接受對應開發工具授權。

    python3 tools/setup_android.py
    python3 tools/build_android.py

預設工具位於 checkout 旁的 /workspace/toolchains。可用兩個腳本的 --toolchain 參數指定其他位置。使用既有 checkout，不需要另外建立 Git worktree。

安裝器核對官方 Godot SHA512、Android command-line tools 官方 SHA1、Gradle SHA256 與 Temurin JDK SHA256；SDK 套件由官方 sdkmanager 管理。全程保留 TLS 與校驗。既有環境若提供無密碼的 HTTPS 代理，會替 Gradle 設定 Java 代理；不會把代理密碼存進腳本。

在有系統 Java 憑證庫的 Linux 環境，使用 /etc/ssl/certs/java/cacerts，讓 JDK 信任環境提供的代理憑證；不會停用憑證驗證。

使用官方 Gradle 模板建置，避免 Godot 4.6.3 舊式 APK 重寫流程將不同 provider authority 改成相同值。產生的 android/build 是忽略的建置資料，保留官方原始內容；wrapper 僅設定本機已校驗的 Gradle 發行檔及官方校驗值。

匯出預設未開啟 Godot 遠端一鍵部署，因此雲端建置不會自動啟動 adb。要在個人電腦使用 USB 部署，可在匯出設定將 Android 設為 runnable，並依 Android 文件開啟 USB 偵錯。

建置腳本會先跑遊戲測試，再建立暫存 APK，成功驗證後才替換正式輸出；報告與 SHA256 位於 build/android。測試金鑰在工具目錄的 keys 中，不在 Git 內；保留同一把測試金鑰才能覆蓋安裝。

macOS／Windows 請用 Godot 編輯器安裝相同版本匯出模板、完整 JDK 17、SDK API 36、Build-Tools 36.1.0 及 NDK 29.0.14206865，啟用 Gradle 並安裝 Android build template，再設定 debug keystore 匯出 APK。

## 驗證範圍

建置驗證包含遊戲測試、簽章、APK 對齊、ARM64 ELF 的 16 KB 頁面相容設定、啟動入口、權限、provider 唯一性、必要遊戲檔案及排除開發資料。這些檢查不能取代手機上安裝與實際遊玩；本次未連接實體手機，也未執行 Android 模擬器。
