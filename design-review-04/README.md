# 提案04：夏季與日常生活（待審）

![設計稿](proposal.png)

本頁是設計審閱稿，**沒有放入遊戲資產或APK**。0.25的設施功能暫用先前通過的水井、桌子、櫃架素材。待通過後才製作正式圖集、校正腳底定位與動畫，再整合入遊戲。

- 夏季作物：番茄（支架栽培）、茄子（矮叢）、蓮藕（獨立栽培水槽，不直接塞進旱田）。每種需幼苗、成長、開花、成熟及收成圖示。
- 初步數值提案：番茄種子20／5照料日／售70；茄子24／6日／售90；蓮藕28／7日／售110。這些只是設計值，沒有加入商店、存檔或現有作物清單。
- 設施外觀：分流水槽、照料工作檯、保鮮貨架。木石、青瓷、藍瓦的色系承接通過的莊園；正式版需按固定施工格尺寸縮減裝飾。
- 居民方向圖：先示範艾德里克、素月的前側背面與素月四姿步態，核對披風、盾牌、狐尾輪廓。圖中不是完整九位居民八方向圖集；通過方向後再逐位製作。

風格沿用提案02；全部原創，東西方奇幻共存。此圖為概念稿，比例、步態與像素規格仍需正式製作，不可直接當作行走sprite sheet。
