# Approved autumn production art

User approved Proposal05. These production atlases were generated separately from the concept board; no board crops are used as game sprites. PNG originals are copied unchanged from image generation output. Geometry registration reads alpha bounds only: `python3 tools/register_autumn_art.py`.

- `crops.png`: 15 frames, three crops × five growth/item stages.
- `objects.png`: moon lantern, basket, celadon pot, grape press, ginkgo, maple, harvest table, fallen leaves.
- Runtime import limit768, nearest filtering; renderer scales original1536×1024 bounds to actual imported texture dimensions. Original full resolution remains in source control.

No new character identities or redesigns are included in this release. The approved existing residents and heroes remain in use.
